## Быстрый запуск (PowerShell)

Требования: Node.js версии 22.13 или выше, npm и запущенный Docker Desktop
с контейнерами Linux.

```powershell
cd E:\reservet
npm ci
# Только при первом запуске, если .env ещё нет:
Copy-Item .env.example .env
npm run db:up
npm run db:migrate
npm run dev
```

Откройте **http://localhost:3000**. Режим **Демонстрация** работает даже без
PostgreSQL: можно создавать столики, искать их, фильтровать и менять статусы.
При перезагрузке изменения сбрасываются. Выберите **Мой локальный API** для проверки
эндпоинтов, которые реализует начинающий разработчик. Этот режим показывает реальные
ошибки и не заменяет данные примерами. Вход в систему — отдельное будущее задание.

Интерфейс доступен на **испанском, английском и русском**. Переключатель находится
в шапке; выбор сохраняется в браузере. Переводы находятся в `public/i18n.js`.
Названия, введённые пользователем, и контракт API не переводятся.

В другом терминале: `Invoke-RestMethod http://localhost:3000/health/db`.

Уже подготовлены сервер, проверки состояния, конфигурация PostgreSQL в Compose,
исполнитель миграций, начальная схема столиков и интерфейс для подключения API.
Бизнес-эндпоинты остаются заданиями. SQS появится на следующем этапе.

`npm run typecheck` проверяет типы; `npm run build` собирает проект;
`npm start` запускает сборку; `npm run db:down` останавливает PostgreSQL,
сохраняя данные. Учётные данные из примера предназначены только для локальной
разработки. PostgreSQL доступен на локальном порту **5433**.
